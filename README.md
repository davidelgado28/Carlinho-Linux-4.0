# Carlinho OS 

Sistema operacional Linux focado em desenvolvimento, compilado automaticamente via GitHub Actions.

##  Software Incluído

- **VS Code** - Editor de código
- **Firefox** - Navegador web
- **GCC/G++** - Compiladores C/C++
- **Python 3** - Linguagem Python
- **Git** - Controle de versão
- **Thunar** - Gerenciador de arquivos
- **GNOME System Monitor** - Gerenciador de tarefas
- **Terminator** - Terminal

## ️ Build

A ISO é construída automaticamente via GitHub Actions a cada push na branch main.
